# Google Play 출시 준비 (Android)

Play Console 에 그대로 붙여 넣을 값과, 출시 전에 해야 할 일. 앱 동작 기준: 2026-11-10.

## 0. 공개 페이지 (GitHub Pages)

`site/` 폴더가 그대로 웹사이트다 (`index.html`, `privacy.html`, `delete-account.html`).

1. GitHub 에 저장소를 만든다 (예: `econary`). 공개 저장소여야 무료 Pages 를 쓸 수 있다.
   비공개로 두고 싶으면 `site/` 만 담은 별도 공개 저장소(예: `econary-site`)를 만든다.
2. 저장소 **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, 폴더 = `/site`
   (`/site` 를 고를 수 없으면 `/ (root)` 저장소에 `site/` 안의 파일만 올린다).
3. 몇 분 뒤 `https://<GitHub 아이디>.github.io/<저장소>/` 가 열린다. 아래에서 쓰는 주소:
   - 개인정보처리방침: `https://<아이디>.github.io/<저장소>/privacy.html`
   - 계정 삭제: `https://<아이디>.github.io/<저장소>/delete-account.html`

> Play 정책상 개인정보처리방침은 **앱 안에서도** 열 수 있어야 한다. 주소가 정해지면 앱 계정 화면에 링크를 넣는다 (남은 일 참고).

### 간단한 설명 (80자)

```
시험일에 맞춘 하루 단어 계획, 퀴즈와 복습으로 TESAT 경제·시사 어휘를 준비해요.
```

### 자세한 설명 (4,000자)

```
TESAT(경제이해력검증시험)을 준비한다면, 시험까지 남은 날에 맞춰 경제·시사 어휘를 계획대로 공부하세요.

■ 시험일에 맞춘 학습 계획
응시할 TESAT 회차와 하루 공부 시간을 고르면, 시험 전까지 배울 수 있는 단어 수를 계산해 매일 새 단어를 정해 드려요. 시험 전 마지막 7일은 복습에 집중하도록 계획이 바뀝니다. 계획은 언제든 바꿀 수 있어요.

■ 오늘의 단어
중요한 경제 용어부터 하루 분량씩 공부해요. 뜻을 읽고, 퀴즈 한 문제로 바로 확인합니다.

■ 잊을 때쯤 다시 나오는 복습
퀴즈를 푼 단어는 기억이 흐려질 때쯤 복습 목록에 다시 나타나요. 틀린 단어는 더 자주 만납니다.

■ 진도와 연속 학습
지금까지 배운 단어 수, 퀴즈 정답률, 최근 5주의 학습 기록을 한눈에 볼 수 있어요.

■ 가입 없이 바로 시작
회원가입 없이 바로 공부할 수 있고, 원하면 Google 또는 Apple 계정을 연결해 기기를 바꿔도 기록을 이어 갈 수 있어요.

■ 함께 고쳐 가는 콘텐츠
뜻이나 퀴즈에서 잘못된 부분을 발견하면 앱에서 바로 신고해 주세요. 확인 후 수정합니다.

Econary 는 economics dictionary 의 줄임말입니다. 한국경제신문의 TESAT 와 제휴하거나 공식 인증을 받은 앱이 아닙니다.
```

### 데이터 보안 (Data safety)

- 데이터를 수집하거나 공유하나요? **수집함 / 공유하지 않음** (Supabase·Google·Apple 은 처리 위탁(서비스 제공업체)이라 '공유'가 아님)
- 전송 중 암호화: **예**
- 데이터 삭제 요청 방법 제공: **예** (앱 안 + 위 웹 링크)

| 데이터 유형 | 수집 | 필수/선택 | 목적 |
|---|---|---|---|
| 개인 정보 → 이메일 주소 | 예 | 선택 (계정 연결 시) | 계정 관리 |

## 3. 출시 전 남은 일

1. **Play 개발자 계정** ($25, 개인) + 본인 인증.
2. 첫 프로덕션 빌드: `apps/mobile` 에서 `npx eas-cli@latest build -p android --profile production` → `.aab`.
   빌드 번호(versionCode)는 EAS 가 관리하며 매번 자동으로 올라간다 (`eas.json` 의 `appVersionSource: remote`).
3. Play Console 에 앱 생성 → `.aab` 를 **비공개 테스트** 트랙에 업로드.
4. **Play 앱 서명 SHA-1** (Play Console → 테스트 및 출시 → 앱 무결성) 으로 Google Cloud 에 Android OAuth 클라이언트를 하나 더 만든다. 없으면 Play 에서 받은 앱의 Google 로그인이 '취소'로 끝난다.
5. 테스터 12명 이상이 14일 연속 참여 → 프로덕션 출시 신청 (신규 개인 계정 규정).
6. (선택) `eas submit` 자동 업로드: Play Console 의 서비스 계정 JSON 키가 필요하다.
